🚀 PRÓXIMOS PASOS (EN ORDEN)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  INSTALAR NODE.JS (OBLIGATORIO)
    ↳ Ve a https://nodejs.org y descarga LTS
    ↳ Ejecuta el instalador
    ↳ REINICIA tu computadora

2️⃣  INSTALAR DEPENDENCIAS
    ↳ Abre PowerShell en esta carpeta
    ↳ Ejecuta: npm install
    ↳ Espera 5-10 minutos

3️⃣  COMPILAR LA APP
    ↳ npm run build
    ↳ npm run cap:sync

4️⃣  ELEGIR PLATAFORMA

    PARA ANDROID (Windows/Mac/Linux):
    ─────────────────────────────────
    ↳ Instala Android Studio
    ↳ npm run cap:add:android
    ↳ npm run cap:open:android
    ↳ Compila en Android Studio

    PARA iOS (Solo Mac):
    ────────────────────
    ↳ Instala Xcode
    ↳ npm run cap:add:ios
    ↳ npm run cap:open:ios
    ↳ Compila en Xcode

📊 PERSONALIZACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Cambiar nombre de app:
  → Edita capacitor.config.ts
  → appName: 'TU_APP'

Cambiar ID de app:
  → Edita capacitor.config.ts
  → appId: 'com.tudominio.app'

Cambiar colores:
  → Edita src/index.html
  → Busca :root { --blue, --green, etc. }

Conectar a tu API:
  → Usa src/api.ts como template
  → Edita src/main.ts con tus endpoints

❓ FAQ RÁPIDO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

P: ¿Necesito Mac para iOS?
R: Sí, solo en Mac puedes compilar para iOS. Android funciona en Windows/Mac/Linux.

P: ¿Cómo conecto mi API?
R: Edita src/main.ts y usa fetch() o axios. Ver EJEMPLOS.md #1.

P: ¿Los datos se guardan sin internet?
R: Sí, src/api.ts incluye sincronización offline automática.

P: ¿Dónde publico la app?
R: Google Play Store (Android) y App Store (iOS). Ver README.md.

P: ¿Puedo cambiar el diseño?
R: Sí, todo está en src/index.html. Es HTML/CSS puro.
