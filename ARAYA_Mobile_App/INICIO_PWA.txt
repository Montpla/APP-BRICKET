🎯 ¿QUÉ ES ESTA CONFIGURACIÓN?

   Una **Progressive Web App (PWA)** es tu app como página web que:

   ✨ Se instala en iOS/Android como app nativa
   ✨ SIN App Store
   ✨ SIN compilación compleja
   ✨ Compartir un simple link
   ✨ Actualizaciones automáticas
   ✨ Funciona offline
   ✨ Dinámico - cambios en tiempo real

🚀 FLUJO: Cómo funciona

   TÚ:
   1. Editas código (src/main.ts, etc.)
   2. npm run build
   3. Subes a Vercel
   4. Compartes link: https://tu-app.vercel.app

   USUARIO (iOS):
   1. Abre link en Safari
   2. Compartir → Agregar pantalla inicio
   3. ¡App instalada! 🎉

   USUARIO (Android):
   1. Abre link en Chrome
   2. Menú → Instalar app
   3. ¡App instalada! 🎉

🌐 PUBLICAR EN LÍNEA (Opción: Vercel)

   1. Ve a https://vercel.com
   2. Sign up (gratis, puedes usar Google)
   3. Click: "New Project" o "New"
   4. OPCIÓN A (Recomendado):
      - Arrastra la carpeta dist/
      - Deploy automático en 1 minuto
   5. OPCIÓN B:
      - Conecta tu GitHub
      - Auto-deploy con cada push
   6. Tu app en: https://[nombre].vercel.app

     const response = await fetch('https://tu-api.com/data');
     const data = await response.json();
     updateUI(data);
   }

   window.addEventListener('load', loadData);
