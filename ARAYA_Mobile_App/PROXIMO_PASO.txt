🚀 PRÓXIMO PASO: 12 COMANDOS (SÍ, SOLO 12!)

   Abre PowerShell y ejecuta ESTO (en orden):


   1️⃣  npm install -g eas-cli expo-cli
       (Instala herramientas de Expo)


   2️⃣  eas login
       (Login en tu cuenta Expo - crea una gratis en https://expo.dev)


   3️⃣  cd "C:\Users\Usuario1\iCloudDrive\Proyecto Araya\Finanzas ARAYA\ARAYA_Mobile_App"
       (Navega a la carpeta)


   4️⃣  npm install
       (Instala dependencias - toma 5-10 minutos)


   5️⃣  npm run eas:build:ios
       (Compila tu app en la nube - toma 10-20 minutos)
       → Espera a que diga "✓ Build complete!"


   6️⃣  Crea cuenta Apple Developer: https://developer.apple.com
       (Paga $99 USD - necesario para publicar)


   7️⃣  Encontra tu Team ID en https://developer.apple.com/account
       (Copia el "Team ID" - son 10 caracteres)


   8️⃣  Edita eas.json:
       - Reemplaza "tu-email@example.com" con tu email Apple
       - Reemplaza "TU_TEAM_ID" con tu Team ID


   9️⃣  Crea contraseña de app: https://appleid.apple.com
       (Security → App-Specific Passwords → Generate)
       Copia la contraseña de 16 caracteres


   🔟  npm run eas:submit:ios
       (Publica en App Store)
       Ingresa tu email Apple y la contraseña de 16 caracteres


   1️⃣1️⃣ Espera revisión (1-3 días normalmente)
       Apple revisa y publica automáticamente


   1️⃣2️⃣ ¡Publicada en App Store! 🎉

❓ PREGUNTAS FRECUENTES

   P: ¿Necesito Mac?
   R: NO. EAS Build compila en servidores de Expo.

   P: ¿Qué es eas.json?
   R: Tu configuración para compilar y publicar. Ya lo creamos.

   P: ¿Qué es app.json?
   R: Metadatos de tu app (nombre, versión, permisos iOS, etc.).

   P: ¿Cuánto cuesta Expo?
   R: Free tier es gratis. Pro es $99/mes (opcional).

   P: ¿Cuánto cuesta Apple Developer?
   R: $99 USD/año. Obligatorio para publicar en App Store.

   P: ¿Cuánto tarda la compilación?
   R: Primera vez: 15-20 minutos. Siguientes: más rápido.

   P: ¿Cómo actualizo la app?
   R: 1. Cambias código. 2. npm run eas:build:ios. 3. npm run eas:submit:ios.

   P: ¿Dónde veo el progreso?
   R: https://expo.dev (tu dashboard personal)
