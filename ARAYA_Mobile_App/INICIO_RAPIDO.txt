📱 PARA ANDROID:

   Opción A - Emulador (en tu PC):
   ─────────────────────────────────
   1. Instala Android Studio: https://developer.android.com/studio
   2. Crea un emulador virtual en Android Studio
   3. Ejecuta en PowerShell:
      npm run cap:add:android
      npm run cap:open:android
   4. En Android Studio: Build > Build Bundle(s) / APK(s) > Build APK(s)

   Opción B - Dispositivo físico:
   ──────────────────────────────
   1. Habilita "Modo de desarrollador" en tu teléfono
      (Ajustes > Acerca de > Número de compilación x7)
   2. Activa "Depuración USB" en Opciones de desarrollador
   3. Conecta por USB a tu PC
   4. Ejecuta:
      npm run cap:add:android
      npm run cap:open:android
   5. En Android Studio: Click el botón Run (▶️)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🍎 PARA iOS (Solo en Mac):

   1. Instala Xcode desde App Store
   2. Instala CocoaPods:
      sudo gem install cocoapods
   3. Ejecuta:
      npm run cap:add:ios
      npm run cap:open:ios
   4. En Xcode: Click Run (▶️)

🔄 ACTUALIZAR LA APP (importante):

   Cada vez que cambies código en src/index.html o src/main.ts:

   npm run build
   npm run cap:sync

   Luego rebuild en Android Studio o Xcode.

🌐 CONECTAR TUS DATOS REALES:

   Por defecto, la app usa datos de prueba. Para conectar tu API:

   1. Edita: src/main.ts
   2. Reemplaza las constantes de datos
   3. Usa la función syncData() para obtener datos de tu servidor
   4. Rebuild: npm run build && npm run cap:sync

   Ejemplo:
   ─────────
   async function loadData() {
     const data = await fetch('https://tu-api.com/datos');
     updateUI(data);
   }
